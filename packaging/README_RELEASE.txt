CourseBot v1.9.5  Windows 免安装版
=================================

一、怎么启动
------------
1. 解压整个压缩包到任意英文/中文目录；
2. 必须保留 CourseBot.exe 和 _internal 文件夹在同一目录，不要只复制 exe；
3. 双击 CourseBot.exe。

不需要安装 Python、OpenCV 或 PyInstaller。

二、首次使用
------------
1. 先在浏览器打开课程视频页面，保持浏览器在前台；
2. 启动 CourseBot，确认顶部目标窗口是课程浏览器；
3. 点击“扫描预览”，确认识别到播放时间、目录、橙色 1/2 或题目；
4. 首次建议勾选“试运行”，观察日志后再取消试运行正式运行；
5. 运行时本窗口会自动最小化，按 F8 可紧急停止。

首次运行会在 CourseBot.exe 同级目录生成：
- config.json：设置和 API Key（明文，不要外传）
- logs/：运行日志、调试截图

三、提示
--------
- 浏览器不要最小化；切到其他窗口时程序会暂停点击。
- “橙色 1”表示视频已看、测验未做，程序会优先补测；
- 视频弹题会直接作答，不滚动；章节测验才会滚动；
- 黄色任务点会自动开始/继续播放；
- 程序检测到画面仍在变化时不会误点暂停；
- 如 Windows 弹出 SmartScreen，可选择“更多信息 → 仍要运行”（本程序未做数字签名）。
- 使用前请确认课程平台允许自动化；账号和成绩风险由使用者自行承担。

四、常见问题
------------
1. 双击没反应：确认 _internal 文件夹完整；查看 logs/ 下是否有 crash 日志。
2. 提示缺少 DLL：安装 Windows 常用运行库（VC++ 2015-2022 x64）。
3. 识别不到时间：先把鼠标移到视频上让控制栏出现，再点“扫描预览”。
4. F8 失效：可能被其他软件占用，用界面“停止”按钮。
5. 换电脑：整个文件夹一起复制，config.json 和 logs 会跟随。
