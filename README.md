# 网课自动学习助手（CourseBot）v2.0.0-dev.1

> 本地测试版，未推送远程。整页视频及目录切换已有 Windows 实页验证，详细范围见 docs/VALIDATION.md。

Windows 桌面端网课自动化工具：

**整页浏览器可访问性清单 + 单一播放决策器 + OpenCV / RapidOCR + Tkinter GUI + LLM**

> 仅用于你本人有权访问、且平台规则允许自动化的学习页面。请遵守课程平台使用条款。

---

## 1. 主要功能

- 监控视频播放进度，自动处理暂停/缓冲；
- 先读取整页播放器及各自任务点状态，再按顺序处理未完成视频；不以当前截图数量、视频时长或目录数字推断整页任务；
- 播完后逐步扫描同页其他视频；仍有无法识别的未完成视频或未能确认滚动结束时停止，避免直接跳节；
- 整页模式根据各播放器独立的时间和播放状态恢复中途暂停，不根据静止幻灯片判断暂停；
- 黄色任务点（视频未完成）自动开始或继续播放；
- 黑屏/大播放按钮页面用 OpenCV 检测中央播放圆钮；
- 视频结束后优先做「章节测验」，完成后再点「下一节」；
- 章节测验自动滚动到真正顶部，再逐题向下识别；向下滚动改为 3 格防止整屏漏题，提交前按题号自检，缺题先重扫；题干与题号同行的判断题会合并识别，分节标题不会当成选项；
- 自动提交、处理「确认提交?」弹窗、识别结果页并进入下一节；确认框提示还有未做题时自动取消并重新扫描补齐；
- 视频上的单题弹窗不调用 LLM，直接本地枚举；支持单选、多选、判断；
- 弹题多选固定遍历全部 `2^N-1` 种非空组合（4 选项 15 种、5 选项 31 种），无截断；每次提交前按蓝/紫选中状态精确校正；单选/判断直接点目标选项，不做多选校验；
- 识别右侧目录的完成/待办标记：绿色对勾跳过，橙色进入后再识别任务类型，不从数字推断视频或测验；
- 当前页任务完成后按整页目录选择橙色待办，进入后重新识别实际任务类型；
- 时间 OCR 丢失但画面仍在变化时，判定为播放中，不误点暂停；
- 视频在播放但控制栏/时间长期不可见时，持续监控，不直接退出；
- 鼠标点击使用 SendInput，并在日志中记录点击前后坐标；
- F8 紧急停止、试运行、日志和调试截图。

## 2. 运行要求

- Windows 10 / 11 x64；
- 源码运行需要 Python 3.10+（测试环境 Python 3.13）；
- 发布版无需安装 Python，解压即用；
- 浏览器打开课程页面并保持前台；
- 联网调用 LLM（答题需要）。

## 3. 发布版使用

1. 本地修复包为 `CourseBot-v2.0.0-dev.1-win64.zip`；旧基线另存，均未发布到 GitHub。解压完整目录；
2. 必须保留 `CourseBot.exe` 和 `_internal` 文件夹在同一目录；
3. 双击 `CourseBot.exe`；
4. 首次运行会在 exe 同级生成：
   - `config.json`：设置和 API Key（明文，不要外传）；
   - `logs/`：运行日志、调试截图；
5. 选择目标浏览器窗口，先点「扫描预览」确认时间/目录/题目识别；
6. 首次建议勾选「试运行」，观察日志后再正式运行；
7. 按 **F8** 可随时紧急停止。

发布版未做数字签名，Windows SmartScreen 可能提示“仍要运行”。

## 5. 自动流程

### 启动时：先盘点整页
1. 选择独立浏览器中的有效课程学习页；找不到课程窗口时不自动选择前台其他应用；
2. 读取整页可访问性树，输出视频总数、已完成顺序、未完成顺序和状态未知项；
3. 只选择最靠前的未完成视频；已完成项不点击播放；
4. 当前页所有视频任务点完成后，处理本节测验或进入目录中的其他橙色待办；
5. 状态未知、读取截断或章节正文尚未同步时，不根据部分截图猜测并点击。

新视频决策使用 `course_state.py`；Windows 适配器为 `accessibility.py`。`video_engine=legacy_ocr` 可显式启用旧截图路径以便对照排查，该模式不保证整页盘点能力。

### 视频播放
- 黄色任务点会自动开播；
- 黑屏页面用 OpenCV/HoughCircles 找中央播放按钮；
- 时间 OCR 丢失时比较视频区域两帧：
  - 画面变化 → 正在播放，不点击；
  - 画面静止 → 尝试点击播放；
- 视频播放但控制栏/时间长期隐藏时，持续移动鼠标唤出控制栏并定期重试 OCR，不会直接退出。

### 视频结束
1. 检查当前小节是否已打绿勾；已打勾则不再重复测验；
2. 若有「章节测验」标签，点击进入；
3. 自动滚到顶部，读取「题量」；
4. 逐题 OCR + LLM 作答并勾选；
5. 滚动页面直到全部题目完成；
6. 点击「提交」；
7. 出现「确认提交?」→ 点击弹窗里的「提交」；
8. 结果页出现后点击「下一节」。

### 视频上的单题弹窗
- 只做 OCR + LLM + 点击选项/提交，**不滚动**；
- 出现「回答错误」且仍有选项与提交时，自动枚举其他答案重新提交；
- 判断题逐个选项，单选题逐个选项，多选题最多 20 种组合。

## 6. 目录状态说明

| 显示 | 可以确认的信息 | 处理方式 |
|---|---|---|
| 绿色对勾 | 该行显示为已完成 | 不作为待办重复进入 |
| 橙色数字 | 该行仍有待办标记 | 进入页面后再识别视频、测验、阅读等实际类型 |

橙色 1 不等于“视频已看、只剩测验”，橙色 2/3 不等于视频数量。视频完成状态只看每个播放器自己的任务点。

## 7. 鼠标 / 输入说明

- 点击优先使用 Windows `SendInput`，失败时回退旧 API；
- 日志会记录目标坐标、点击前后鼠标坐标和使用的方法；
- 如果鼠标无法移动到目标位置，程序会停止并提示可能被安全软件/权限/远程控制拦截，而不是继续“假点击”；
- 如果日志显示鼠标坐标正常变化但页面无反应，通常是浏览器权限或远程控制软件拦截；
- 程序与浏览器最好使用相同权限级别运行；
- 为避免系统环境变量 `SSLKEYLOGFILE` 指向被占用文件导致启动失败，程序启动时会清除该变量。

## 8. 设置项

### 运行
| 设置 | 说明 |
|---|---|
| 视频结束后自动进入下一节 | 章节测验完成后再切下一节 |
| 自动答题 | 弹题 + 整页章节测验 |
| 视频暂停时自动恢复播放 | 画面静止时才点击播放 |
| 试运行 | 只识别不点击 |
| 开始时最小化 | 防止遮挡浏览器 |
| 窗口置顶 | 可选 |
| 最多连续学习 | 防止无限切换 |
| 无进度判定 | 默认 8 秒 |
| 结束判定余量 | 默认 2 秒 |
| 答题重试 | 答错枚举 |

### LLM
- **云端 API**：API 地址、API Key、模型名、超时、最大输出、温度；
- **本地模型（Ollama）**：
  - 默认接口 `http://127.0.0.1:11434/api/chat`；
  - 默认模型 `qwen3:4b`；
  - 需要先安装并启动 Ollama，且已 `ollama pull qwen3:4b`；
  - 不需要 API Key；
  - 「检测本地模型」可列出本机已安装模型；
  - 也可填 OpenAI 兼容的 `/v1/chat/completions` 地址；
- 默认关闭深度思考（`thinking: disabled`/`/no_think`），更快更稳定；
- 点击「测试 LLM 连接」验证。
- 本地 4B 小模型准确率明显低于云端模型，重要答题建议用云端。

### 高级
- 轮询间隔、整页扫描间隔、实时预览、调试截图；
- 打开日志/配置目录；
- 恢复默认设置。

## 9. 常见问题

### 启动失败：`Permission denied: D:\Downloads\netdump\log.log`
- v1.3.1 起已修复：程序会清除系统 `SSLKEYLOGFILE` 环境变量；
- 如果没有生效，请在系统环境变量中删除 `SSLKEYLOGFILE` 后重启程序。

### 提示“鼠标操作失败”
- 查看日志里的“鼠标 before->after”；
- 检查是否被安全软件、远程控制（ToDesk 等）或权限级别拦截；
- 尝试以与浏览器相同权限运行；
- 确认浏览器在前台。

### 视频已经播放但程序说没时间/停止
- v1.3.2 起有“无时间播放监控”，会持续移动鼠标唤出控制栏；
- 如果仍出现，请把最新 `logs/run_*.log` 和 `preview_last.jpg` 留作排查。

### 章节测验没有滚动
- 整页测验才会滚动；单题弹窗不会滚动；
- 如果页面是 iframe/懒加载，可能停在原页，请手动完成并重启。

### 切换下一节失败
- 检查右侧目录是否展开；
- 查看 `logs/*_nav_failed.jpg`。

### F8 不生效
- 可能被其他软件占用；用界面「停止」。

## 12. 安全说明

- `config.json` 中 API Key 为明文，不要公开分享；
- 源码和发布包不内置任何 API Key，请在 GUI/`config.json` 中填写，或设置 `COURSEBOT_API_KEY` / `ARK_API_KEY`；
- 日志和调试截图可能包含课程内容；
- 自动答题准确率不保证，请勿用于重要考试；
- 平台若要求人脸/摄像头/验证码，本工具无法绕过。

## 13. 多视频回归测试

在 Windows 源码环境安装依赖后执行：

```powershell
python -m unittest discover -s tests -v
```

测试覆盖多播放器选择、相同时长、任务点状态关联、滚动后的坐标重定位、进度重置、窗口偏移和扫描失败停止。桌面输入使用替身，不操作真实浏览器。
